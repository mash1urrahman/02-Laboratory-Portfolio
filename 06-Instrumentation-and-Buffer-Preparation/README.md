## 2. Standard Molecular & Biochemical Buffer Formulations (CHE 203 / BBT Labs)

| Solution / Buffer | Final Concentration & pH | Exact Formulation Protocol |
| :--- | :--- | :--- |
| **$1\ \text{M}$ Tris-HCl Stock** | $1.0\ \text{M}$, $\text{pH } 8.0$ ($500\ \text{mL}$) | Dissolve $60.57\ \text{g}$ Tris base ($\text{MW } 121.14$) in $350\ \text{mL}$ distilled $\text{H}_2\text{O}$, adjust $\text{pH}$ to $8.0$ with conc. $\text{HCl}$, and bring to $500\ \text{mL}$. |
| **$0.5\ \text{M}$ EDTA Stock** | $0.5\ \text{M}$, $\text{pH } 8.0$ ($500\ \text{mL}$) | Add $93.06\ \text{g}$ $\text{Na}_2\text{EDTA}\cdot 2\text{H}_2\text{O}$ ($\text{MW } 372.24$) to $350\ \text{mL}$ $\text{H}_2\text{O}$; add $\text{NaOH}$ pellets slowly while stirring until $\text{pH } 8.0$ (required for complete dissolution), then bring to $500\ \text{mL}$. |
| **$10\times$ TE Buffer Stock** | $100\ \text{mM}$ Tris-HCl, $10\ \text{mM}$ EDTA, $\text{pH } 8.0$ ($1000\ \text{mL}$) | Combine $100\ \text{mL}$ of $1\ \text{M}$ Tris-HCl ($\text{pH } 8.0$) + $20\ \text{mL}$ of $0.5\ \text{M}$ EDTA ($\text{pH } 8.0$) + $880\ \text{mL}$ nuclease-free $\text{H}_2\text{O}$; autoclave. *(Dilute $1:10$ for $1\times$ TE working buffer: $10\ \text{mM}$ Tris, $1\ \text{mM}$ EDTA).* |
| **$1\times$ PBS Buffer** | $137\ \text{mM}$ NaCl, $2.7\ \text{mM}$ KCl, $10\ \text{mM}$ $\text{Na}_2\text{HPO}_4$, $1.8\ \text{mM}$ $\text{KH}_2\text{PO}_4$, $\text{pH } 7.4$ ($1000\ \text{mL}$) | Dissolve $8.00\ \text{g}$ NaCl, $0.20\ \text{g}$ KCl, $1.44\ \text{g}$ $\text{Na}_2\text{HPO}_4$, and $0.24\ \text{g}$ $\text{KH}_2\text{PO}_4$ in $800\ \text{mL}$ $\text{H}_2\text{O}$; adjust $\text{pH}$ to $7.4$ with $\text{HCl}$ and bring to $1000\ \text{mL}$. |
| **$1\ \text{M}$ & $1\%\ (\text{w/v})$ $\text{NaOH}$** | $1.0\ \text{M}$ / $1\%$ ($100\ \text{mL}$) | Dissolve $4.00\ \text{g}$ $\text{NaOH}$ (for $1\ \text{M}$) or $1.00\ \text{g}$ $\text{NaOH}$ (for $1\%$) in $\sim 70\ \text{mL}$ cool distilled $\text{H}_2\text{O}$ and dilute to $100.0\ \text{mL}$. |
| **$1\ \text{M}$ Mineral Acids** | $1.0\ \text{M}$ ($100\ \text{mL}$) | Calculated via $M_1V_1 = M_2V_2$ (always adding acid slowly to water): $8.26\ \text{mL}$ conc. $\text{HCl}$ ($12.1\ \text{M}$), $6.33\ \text{mL}$ $\text{HNO}_3$ ($15.8\ \text{M}$), $5.43\ \text{mL}$ $\text{H}_2\text{SO}_4$ ($18.4\ \text{M}$), or $8.62\ \text{mL}$ $\text{HClO}_4$ ($11.6\ \text{M}$) brought to $100.0\ \text{mL}$. |
